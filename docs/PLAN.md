# Release status

The original build schedule has been superseded by the
[final submission plan](FINAL_SUBMISSION_PLAN.md) and
[repository audit](REPO_AUDIT_2026-10-27.md).

The release scope is the real parameter-to-Cd model, a domain gate, the
Nemotron tool loop, an observed-result logbook and a matched optimiser
comparison. Surface Cp is an optional experimental visualisation with no
established calibration on generated geometry. Lift and wall shear are unavailable.

Locally prepared submission copy is in [submission.md](submission/submission.md).
Deployment, public YouTube upload and the Devpost form are explicit external
steps. Do not mark them complete from local tests.
